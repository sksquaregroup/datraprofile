## ☁️ Vercel Deployment

1. Import the repository on [Vercel](https://vercel.com).
2. Set **Application Preset** to **`Other`**.
3. Add Environment Variables (**Project Settings &rarr; Environment Variables**):
   * `RESEND_API_KEY`: Your Resend API key (`re_...`)
   * `CONTACT_TO_EMAIL`: `info@sksquaregroup.com`
   * `CONTACT_FROM_EMAIL`: `Datra Platform <info@sksquaregroup.com>`
4. Click **Deploy**.
