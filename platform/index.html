Remote Control

Fix issues in minutes, not site visits.

Browser-based terminal, SSH, remote desktop and capture on any device — plus an 82-command RS232 & PC library for power, brightness, volume and input. No VPN, no callout, full audit trail of every session.

app.datraplatform.com/units · Commands
datra-cli@estate:~$ unit --id LHR-T5-01 --status
[OK] Display link established via Datra Gateway (Latency 14ms)
Screen Model: LG webOS Commercial 75" | Firmware: v04.22.10
datra-cli@estate:~$ rs232-exec --cmd POWER_QUERY
> Response: [0x01, 0x30, 0x41, 0x30, 0x41, 0x02] (POWER_ON)
datra-cli@estate:~$ datra-agent process-check --cms
